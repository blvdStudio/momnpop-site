# Mom & Pop

Site statique extrait de momnpop-site_1.zip, sans modification de la page ou des images.

## Publication sur GitHub Pages

Dans Settings > Pages, choisir Deploy from a branch, puis main et / (root).

## Fonctionnement

Ouvrir index.html pour une prévisualisation locale. Les images utilisent des chemins relatifs.

Le formulaire de contact est une démonstration : aucun message n'est envoyé. Le panier est également une interaction de maquette, sans commande ni paiement.
